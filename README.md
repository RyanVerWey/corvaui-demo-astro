# CorvaUI Astro Demo

Public Vercel showcase using the first-class `@corvaui/astro` integration, `@corvaui/tokens`, and the Graphite token family. Fieldnote House is a multi-route hospitality site with image-led marketing, stay comparison, a booking DataGrid, and revenue reports.

## Routes

- `/` hospitality portfolio launch surface
- `/about/` stay and gathering comparison
- `/data-table/` sortable/filterable booking grid
- `/dashboard/` revenue and arrival reporting
- `/host/` host-desk workflow

## Quality Gate

Run `npm test` to audit dependencies and build the production bundle.
